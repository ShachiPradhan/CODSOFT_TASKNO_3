# CODSOFT_TASKNO_3 — Iris Flower Classification

This repository contains my submission for **Task 3** of the **CodSoft** internship program. The project is implemented as a Jupyter/Colab notebook (`IRIS.ipynb`) and focuses on classifying Iris flowers into their respective species using machine learning.

## 📌 Project Overview

The goal of this task is to build a classification model that can predict the species of an Iris flower — **Setosa**, **Versicolor**, or **Virginica** — based on its sepal and petal measurements. The notebook covers the complete machine learning workflow, from data exploration to model evaluation.
